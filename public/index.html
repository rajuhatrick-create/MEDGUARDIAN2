Diagnostics and commissioning
Dispensing stays locked until every item below is resolved on the device.
    Commissioning steps (see PHYSICAL_TEST_CHECKLIST.md):
    1. Wire the board per HARDWARE_WIRING.md; power the servos from a separate regulated 5 V supply with a common ground.
    2. Run tools/servo_test.py with the horns unattached, then set each servo's mechanical limits and the flap open/closed angles in config.py.
    3. Run tools/limit_switch_test.py, tools/hx711_diag.py and tools/calibrate.py; enter the offset, counts per gram and noise.
    4. Measure each compartment angle and set COMPARTMENT_ANGLES.
    5. Measure the dose window with inert test objects and set DOSE_MIN_DELTA_G / DOSE_MAX_DELTA_G.
    6. Add a lid-closed switch (PIN_LID_SWITCH) and complete the checklist before setting ACTUATION_VERIFIED = True.
