Diagnostics and commissioning
Verify wiring before powering actuators. The current configuration blocks movement until wiring, calibration and actual release paths are verified.
  1. Confirm UART, load-cell, ultrasonic and switch signal directions against HARDWARE_WIRING.md.
  2. Run tools/calibrate.py through mpremote with the servo mechanically disconnected.
  3. Measure unloaded scale offset, counts per gram, empty cup mass and stable noise range.
  4. Measure the cup distance window, tilt and movement limits.
  5. Verify each compartment's complete release and safe return path. Never substitute 0°/120°/240° for SG90 commands.
  6. Enter verified values in config.py. Complete PHYSICAL_TEST_CHECKLIST.md before enabling actuation.
